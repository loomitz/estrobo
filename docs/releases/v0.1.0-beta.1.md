# estrobo v0.1.0-beta.1

Primer candidato de beta pública limitada para macOS. Este archivo describe el prerelease previsto; que exista en `main` no significa que el release ya esté publicado. El workflow debe conservarlo como draft hasta cerrar CI, Macs limpios y gates físicos.

## Novedades

- App nativa en español e inglés para Apple Silicon e Intel, con macOS 13.0 como mínimo.
- Espacios de trabajo locales con perfiles, grupos, modelos de flash, visibilidad y presets.
- Vistas Canales, Inspector y Matriz sobre una sola sesión y los mismos borradores.
- Potencia Manual en pasos de 1/3 EV, M/Auto TTL/Off y modelado apagado, proporcional o fijo.
- Ajuste global relativo, Beep, Standby y Test explícito.
- Entrega Automática predeterminada con debounce de 700 ms y alternativa **Con botón**.
- Protección transaccional de sliders: ningún valor intermedio se transmite mientras el puntero está presionado; al soltar sólo se programa el valor final.
- Sync inicial A0 → A1 serial, confirmaciones GATT/`FEC8` y recuperación fail-closed ante resultado incierto.
- Modo `--mock-radio` explícito que no crea una sesión Bluetooth ni manda comandos físicos.

## Cambio de identidad

El bundle público usa:

- identifier: `mx.loo.estrobo`;
- versión: `0.1.0`;
- build: `1`;
- mínimo: macOS `13.0`.

El identificador anterior pertenecía al prototipo. Este cambio crea una identidad limpia de preferencias/contenedor: radios, códigos, espacios de trabajo y presets del prototipo no se migran automáticamente.

## Privacidad y seguridad

- Sin cuenta, backend, red, analítica ni telemetría de Estrobo.
- App Sandbox y entitlement Bluetooth; sin entitlement de red.
- Recordar el Código del radio es opt-in y comienza apagado.
- Si se elige, nombre/UUID/código se guardan localmente y sin cifrar sólo después de `PWOK` + Sync; **Olvidar** los elimina.
- El Código del radio no es una credencial fuerte, viaja en el protocolo BLE y no debe reutilizar un PIN personal.
- Firma autosignada estable, no Apple. No hay Developer ID ni notarización; la advertencia de Gatekeeper es esperada.

## Semántica de Sync

Conectar significa sobrescribir deliberadamente el A0 global y los A1 de todos los grupos configurados usando el estado local de Estrobo. No existe lectura completa radio → app. `FEC8` no identifica grupo, no devuelve valores y no demuestra el resultado óptico.

Lee [Sincronización automática](../AUTOMATIC-SYNC.md) antes de conectar un transmisor.

## Compatibilidad y límites

El codec y la máquina de estados tienen cobertura determinista. Pruebas físicas históricas confirmaron en un transmisor el enlace `PWOK`/Sync y cambios reversibles A1 de potencia y modelado fijo al 25%, con GATT + `FEC8`; esa evidencia no constituye compatibilidad general.

Siguen sin editarse Multi, canal, compensación TTL no neutra, Código del radio, firmware y OAD. TTL óptico, Beep, Standby, otras intensidades fijas, grupos y firmware deben validarse por combinación física antes de declararlos compatibles. El handshake `Psub`/`PWOK` sigue siendo obligatorio y el Código del radio es el PIN local que utiliza ese flujo.

## Instalación

1. Descarga `estrobo-v0.1.0-beta.1-macos-universal.zip`, `SHA256SUMS` y `estrobo-v0.1.0-beta.1-manifest.json` únicamente desde este GitHub Release.
2. Verifica el SHA-256 antes de extraer.
3. Mueve `estrobo.app` a Aplicaciones e intenta abrirla.
4. Usa **Configuración del Sistema → Privacidad y seguridad → Abrir de todos modos**. No desactives Gatekeeper ni confíes manualmente en el certificado.

Instrucciones completas: [Beta](../BETA.md).

## Gates de publicación

El prerelease sólo puede salir de draft después de:

- CI verde nativo arm64 e Intel;
- ZIP universal con ambas slices, versión/entitlements correctos y Hardened Runtime;
- firma autosignada cuya huella coincide con el certificado público versionado;
- checksum, manifiesto y attestation verificados sobre el asset real;
- smoke con cuarentena intacta en Macs limpios Apple Silicon e Intel;
- gates Bluetooth/reconexión coordinados y baseline reversible;
- aprobación humana del environment `public-beta` y `PUBLIC_BETA_SMOKE_APPROVED_TAG` igual al tag exacto.

Los puntos faltantes no se suavizan en las notas: el release permanece draft. Consulta el [checklist completo](../RELEASE-CHECKLIST.md).
