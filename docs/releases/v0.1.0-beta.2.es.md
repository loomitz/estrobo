# estrobo v0.1.0-beta.2

[English](https://github.com/loomitz/estrobo/blob/v0.1.0-beta.2/docs/releases/v0.1.0-beta.2.md) | **Español**

Primer beta público limitado de Estrobo para macOS. El tag anterior `beta.1` permaneció como candidato interno sin publicar; `beta.2` es el primer prerelease destinado a compartirse.

> [!WARNING]
> Este build usa firma autosignada, no Developer ID de Apple, y no está notarizado. macOS mostrará una advertencia de Gatekeeper. Verifica el checksum y el origen de la descarga antes de abrirlo.

## Compatibilidad de hardware

Estrobo se conecta por Bluetooth a un disparador de flash Godox compatible. No se conecta directamente a los flashes ni a los receptores: éstos continúan comunicándose mediante el sistema de radio Godox del propio disparador y no necesitan Bluetooth.

El disparador debe tener Bluetooth integrado y activado, y exponer el perfil BLE/GATT de Godox Flash compatible con Estrobo. Tener Bluetooth, un nombre Godox o emitir un anuncio BLE no garantiza por sí solo la compatibilidad; las diferencias de modelo y firmware todavía requieren validación física.

La matriz de pruebas físicas usa un disparador Godox X3Pro con Bluetooth activado y flashes Godox AD400Pro II. Estrobo se conecta al X3Pro; los AD400Pro II se comunican mediante el sistema de radio Godox del propio disparador. No se registraron la variante exacta de cámara ni las revisiones de firmware, y esto no garantiza que todas las funciones se hayan validado ópticamente. Otros disparadores que expongan el perfil BLE/GATT compatible y otros flashes del sistema Godox X podrían ser compatibles, pero Estrobo no declara soporte hasta verificar físicamente cada combinación de disparador, flash y firmware. Esta matriz no sustituye el smoke de hardware previo a la publicación que se exige al asset exacto del release.

## Funciones principales

- App nativa en inglés y español para Macs Apple Silicon e Intel con macOS 13.0 o posterior.
- Espacios de trabajo locales con perfiles de transmisor, grupos de trabajo, modelos de flash, visibilidad y presets.
- Vistas Canales, Inspector y Matriz sobre una sesión y estado de borradores compartidos.
- Potencia Manual en pasos de 1/3 EV, M/Auto TTL/Off y modelado apagado/proporcional/fijo.
- Ajuste global relativo, Beep, Standby y Test explícito.
- Entrega automática con debounce de 700 ms o modo **Con botón**.
- Edición transaccional de sliders que sólo envía el valor final después de soltar.
- Sincronización inicial A0 → A1 serial con confirmación GATT/`FEC8` y recuperación fail-closed.
- Modo `--mock-radio` explícito que no crea una sesión Bluetooth ni envía comandos físicos.

## Privacidad y seguridad

- Sin cuenta, backend, entitlement de red, analítica ni telemetría de Estrobo.
- App Sandbox y entitlement Bluetooth activos.
- Recordar un transmisor y Código del radio es opt-in y comienza apagado.
- Nombre, UUID y código recordados se guardan localmente y sin cifrar sólo después de `PWOK` + Sync; **Olvidar** los elimina.
- El Código del radio de seis dígitos es el PIN local del transmisor, no una credencial fuerte ni un secreto de alto valor. No reutilices un PIN personal.

## Comportamiento de Sync y límites

Conectar sobrescribe deliberadamente el A0 global y el A1 de todos los grupos configurados usando el estado local de Estrobo. No existe lectura completa transmisor → app. `FEC8` no identifica grupo, no devuelve valores aplicados ni demuestra un resultado óptico.

La edición Multi está planeada para una versión futura, pero no está disponible en esta beta. Tampoco están disponibles el cambio de canal, la compensación TTL no neutra, el cambio del Código del radio, firmware u OAD. TTL, Beep, Standby, intensidades fijas de modelado, cobertura de grupos y resultados ópticos siguen dependiendo de validación física por modelo/firmware.

Lee [Sincronización automática](https://github.com/loomitz/estrobo/blob/v0.1.0-beta.2/docs/AUTOMATIC-SYNC.md) antes de conectar hardware.

## Descargar e instalar

1. Descarga `estrobo-v0.1.0-beta.2-macos-universal.zip`, `SHA256SUMS` y `estrobo-v0.1.0-beta.2-manifest.json` únicamente desde este GitHub Release.
2. Conserva los tres archivos juntos, abre Terminal en su carpeta y ejecuta `shasum -a 256 -c SHA256SUMS`. Continúa únicamente si tanto el ZIP como el manifiesto muestran `OK`.
3. Descomprime el ZIP, mueve `estrobo.app` a Aplicaciones e intenta abrirla una vez.
4. Después de que macOS bloquee el primer inicio, abre **menú Apple → Configuración del Sistema → Privacidad y seguridad**, baja a **Seguridad**, selecciona **Abrir de todos modos**, autentícate y confirma **Abrir**.

No desactives Gatekeeper, retires la cuarentena ni marques manualmente como confiable el certificado autosignado.

## Verificar la descarga

```sh
shasum -a 256 -c SHA256SUMS
gh attestation verify estrobo-v0.1.0-beta.2-macos-universal.zip \
  --repo loomitz/estrobo \
  --predicate-type https://github.com/loomitz/estrobo/attestations/manual-tag-rebuild/v1
```

La atestación usa el predicado protegido de reconstrucción manual de Estrobo: `main` protegido aportó el workflow y el commit etiquetado aportó todos los insumos del release. El manifiesto registra tag y commit del release, ambas arquitecturas, versión mínima de macOS, digest del certificado de firma y digest del artefacto.

## Soporte e independencia

Reporta problemas de uso y compatibilidad no sensibles mediante [GitHub Issues](https://github.com/loomitz/estrobo/issues). Reporta vulnerabilidades explotables mediante [Private Vulnerability Reporting](https://github.com/loomitz/estrobo/security/advisories/new).

Nunca incluyas un Código del radio real, payload de autenticación, UUID completo, información personal, token, clave o certificado privado en un reporte.

Estrobo es un proyecto independiente. No está afiliado, patrocinado, aprobado ni mantenido oficialmente por Godox. Este repositorio no incluye por ahora una licencia open-source.
