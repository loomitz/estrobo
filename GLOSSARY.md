# Estrobo

Lenguaje del producto para el control local de transmisores y la actualización de Estrobo para macOS.

## Actualizaciones de macOS

**Actualización asistida de Estrobo**:
Cambio a una versión más reciente de la aplicación, con búsqueda y descarga que pueden ocurrir en segundo plano. La instalación y el reinicio requieren la confirmación del usuario.
_Avoid_: Actualización silenciosa, reinicio automático

**Momento seguro para actualizar Estrobo**:
Estado en el que cerrar y reiniciar la aplicación no interrumpe una operación con el transmisor ni pierde cambios pendientes del usuario.
_Avoid_: Aplicación inactiva, ausencia de interacción

**Canal beta de Estrobo**:
Recorrido de actualizaciones para una instalación beta que admite nuevas betas y la transición a una versión estable.

**Canal estable de Estrobo**:
Recorrido de actualizaciones para una instalación estable que ofrece únicamente versiones estables.

**Oferta de actualización de Estrobo**:
Una versión de la aplicación presentada como candidata para una instalación concreta según su canal, versión y compatibilidad. Descargarla no equivale a aceptar su instalación.

**Confirmación de instalación de Estrobo**:
Consentimiento explícito para instalar una oferta concreta y reiniciar la aplicación cuando el trabajo con el transmisor y los cambios locales permitan hacerlo. Cerrar normalmente la aplicación no constituye esa confirmación.
